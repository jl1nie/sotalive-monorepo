サブエージェントから測る: モデルごとに input + cache 作成 + output(cache 読みは括弧の中)。`?` は記録していない
という意味で、推測した値ではない。セッションの全体を数えるので、1 つのセッションで複数の作業をしたときは、あとの行に
それまでの全部が入る。別々のセッションの行を比べるか、同じセッションの行の差を読む。
