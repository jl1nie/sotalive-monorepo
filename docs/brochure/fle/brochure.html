FAST LOG ENTRY FOR SOTA / POTA / WWFF
FLEonline
山や公園での運用ログを、
スマホ 1 台で、その場で書くためのアプリです。

必要最小限の入力で記録

相手のコール以外は自動で入ります。必要最小限の入力で QSO をロギングできます。
40m cw → 0230 ja1abc → 35 ja2xyz

使いやすい GUI

山の上でも手早く操作できるよう、スマホでの使いやすさを第一に作っています。入力した行がどう記録されるかは、候補バーですぐに分かります。

アクティベーション
ゾーンの表示

現在地（GPS）を重ねた地図に、SOTA のゾーンと POTA の公園を表示。予定に入れた山頂の地図は、電波がなくても見られます。

スマホで開いてみてください
fleonline.sotalive.net

電波がなくても書ける

一度開いておけば、電波のない山頂でも書けます。ログは端末に自動で保存されます。

ファイルは一度に作成

SOTA の CSV、POTA・WWFF・SOTA の ADIF、HAMLOG の CSV を、zip でまとめて作れます。

ブラウザーで動く

インストール不要。PC でもスマホでも、ブラウザーがあれば使えます。PC で入れた設定と予定は、スマホに同期できます。
