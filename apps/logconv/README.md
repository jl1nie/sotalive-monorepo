# logconv(LogConverter 新版)

アマチュア無線のログ形式を変換する LogConverter の React + TypeScript + Vite 版です。WSPR はタブとして入っています。
logconv2.sotalive.net でテスト中です。

詳しくは [docs/apps/logconv.md](../../docs/apps/logconv.md) を見てください。

```bash
pnpm --filter @sotalive/logconv dev    # http://localhost:3002/
pnpm --filter @sotalive/logconv test   # テスト
pnpm --filter @sotalive/logconv build  # ビルド(dist)
```
