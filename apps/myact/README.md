# myact(MyActivation の React 版)

SOTA/POTA のアクティベーションを管理する MyActivation の React + TypeScript + Vite 版です。
**開発中**で、myact2.sotalive.net で試しています。本番は旧版(`apps/myact-org`)です。

詳しくは [docs/apps/myact.md](../../docs/apps/myact.md) を見てください。

```bash
pnpm --filter @sotalive/myact dev    # 開発サーバー
pnpm --filter @sotalive/myact test   # テスト
pnpm --filter @sotalive/myact build  # ビルド(dist)
```
